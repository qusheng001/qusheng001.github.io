Projects

NERVE Observer

A runtime observability toolkit for embodied robots that discovers visible assets and passively collects ROS 2, CAN, and host telemetry. A live dashboard shows system activity, while a black box preserves events for replay.

Embodied Security Testbed

A testbed for repeatable robotics security evaluations, combining simulation, runtime telemetry, and experiment replay.

MBS Parking System

A smart-parking prototype focused on simplifying the parking experience and using clear visual cues to guide users through each step.
